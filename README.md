## FModel - An Unreal Engine Archives Explorer in C# Vibecoded to work on linux terminal 

example use 
FModelCli --folder "/game/folder" \                                   ✔ 
  --aes-key 0x....... \
  --ue4-version 4.18 ( or any other u think game is using)

use arrow keys in terminal to navigate in pak files and extract maps / textures / models / animations  


to build just use

```
dotnet build FModelCli.csproj
```
